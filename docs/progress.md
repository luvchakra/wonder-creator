| P0.1-05 Quality Review & Selective Refinement | Done | Studio Quality panel: findings checklist (attention checks + suggestions, stable keys), choose which to apply, "Preview N changes" (always a proposal with a line diff, whatever the autonomy setting), "Try another version", keep or discard; keeping creates a version whose summary names what was applied, with a "Compare with the previous version" link. | P0.1-06 Transformation Workflow | Done | Derivative dialog: source summary, choose which version to adapt, suggested transformations as large cards (any other type under "More kinds"), optional instruction, "What carries over" (source link and version, material, contributors, rights, private-draft review). Someone else's work can be adapted only when they allowed derivatives: their private material never carries over, they're credited as "Original creator" and attribution is required. The derivative opens linked to its source |
| P0.1-07 Rights Detail & History | Done | Rights tab leads with the legal note (records don't by themselves establish legal ownership); ownership, copyright, usage & attribution, contributors, provenance, licenses; step-up for transfer and commercial activation. Shown as a filterable, plain-sentence feed (All / Ownership / Licenses / Publication / Derivatives). Derivative creation checks inherited restrictions (P0.1-06). Rights approvals granted/declined join the history with the Approval Center (P0.1-11) |
| P0.1-08 License Creation & Request | Done | License modes (free, free with license, paid non-exclusive, limited edition, exclusive) and all plan dimensions (use, commercial, modification, derivatives, attribution, resale, exclusivity, territory, duration; fee and edition recorded as terms, no payments). Creator flow in four steps (use & mode → what's allowed → where & when → review; back keeps the draft) → save draft or activate. Requester flow: proposed use + terms → review → send; owner approves (creates an active license for the requester), declines or counters; requester accepts the counter or withdraws. Consequential terms (commercial, paid, limited, exclusive) need the owner's password; CreatorBrain can't act here. Status changes only via security-definer functions; one open request per piece; license terms visible only to owner and licensee; every step in the rights history; owner and requester notified |
