| UI-E | **Words on slide visuals** (owner request): a chosen image gets "Add text" (first on a Carousel). Each slide starts with its own line from the Carousel (`slideTexts` reads "### Slide N" / "**Text:**" and similar), prev/next moves through the set with one shared look: position (Top · Centre · Bottom), look (Shade · Cream band · Clear), size (S · M · L), font (Serif · Sans). Download, or "Add to this Creation" / "Save as Material" via `POST /api/v1/image-generations/:id/text`: the image is inspected like any upload, re-encoded to WebP, and kept as a `derived` Material whose provenance records the source image and the exact words, with lineage to the Creation. Tests: `tests/db/image-generations.test.ts`, `e2e/slide-text.spec.ts`, unit tests for slide parsing and layout | Done |
| UI-E | **Arrange and change slide visuals** (owner request): numbered slides on a Carousel; the chosen image's More menu has Change this image… · Move earlier · Move later (and Save as Material).
